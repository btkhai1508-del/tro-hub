## Migration 0029 (cần migration, CHƯA áp dụng production)
File `cloudflare/migrations/0029_month_people_and_alerts.sql` + bản sao trong `TENANT_MIGRATIONS` (kho riêng) + thêm bảng vào `TENANT_TABLES`. Chỉ thêm, không sửa/xoá dữ liệu.
```sql
ALTER TABLE invoices ADD COLUMN people INTEGER;    -- số người tính tiền của tháng; NULL = hoá đơn cũ (đếm cư dân hiện tại như trước)
ALTER TABLE invoices ADD COLUMN vehicles INTEGER;  -- số xe của tháng, cùng cách
ALTER TABLE notifications ADD COLUMN dedupe_key TEXT;
CREATE UNIQUE INDEX notifications_dedupe ON notifications(dedupe_key) WHERE dedupe_key IS NOT NULL;
CREATE TABLE admin_alerts (                         -- chuông admin; kind không CHECK để sau thêm 'password_reset'
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  house_id TEXT NOT NULL REFERENCES houses(id),
  kind TEXT NOT NULL,                               -- 'invoice_paid' | 'overpaid'
  room_name TEXT, month TEXT, invoice_id INTEGER, amount INTEGER,
  received_at TEXT NOT NULL,                        -- giờ SePay nhận tiền, hoặc lúc đánh dấu
  source TEXT,                                      -- 'sepay' | 'staff:3' | 'recompute'
  dedupe_key TEXT NOT NULL UNIQUE,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX admin_alerts_house ON admin_alerts(house_id, created_at);
CREATE TABLE admin_alert_reads (alert_id INTEGER NOT NULL REFERENCES admin_alerts(id), reader TEXT NOT NULL,
  read_at TEXT NOT NULL DEFAULT (datetime('now')), PRIMARY KEY (alert_id, reader));  -- đã đọc theo từng người
```

## Mục 6: số người theo tháng (cách gọn nhất)
- `recompute`: hoá đơn **nháp** đếm cư dân đã duyệt có ngày vào ≤ cuối tháng của hoá đơn, rồi lưu vào `invoices.people/vehicles`.
  Hoá đơn **đã phát hành** dùng số đã lưu (đóng băng lúc phát hành); NULL (hoá đơn cũ) thì đếm như hiện nay.
- `/api/admin/rooms` trả `soNguoi`/`soXe` = số đã lưu của tháng đó nếu có.

## Worker (cloudflare/src)
- `billing/invoices.ts`: `issueMonth(..., roomIds?)` lọc theo id; tạo thông báo cư dân cho từng hoá đơn vừa phát hành (`INSERT OR IGNORE`, khoá `invoice-issued:<id>`); số người theo tháng; `ensureDraftForRoom` tạo/tính lại nháp cả **tháng đang chuẩn bị** (`prepMonth`) và tính lại nháp hiện có khi thêm/bớt người.
- `routes/admin.ts`: issue-month nhận `roomIds` (số); id không thuộc căn → 400 `ROOM_NOT_IN_HOUSE`, không phát hành gì. `rooms` (tên) vẫn nhận cho tab cũ. Thêm `POST /api/admin/rooms/:roomId/checkout {houseId}`: mọi cư dân của phòng → `moved_out` + ngày ra, xoá nháp tháng sau chưa có tiền của phòng, cập nhật số đếm, audit.
- `billing/alerts.ts` (mới): `addAlert()` dùng chung; `routes/alerts.ts` (mới): `GET /api/admin/alerts` (trả danh sách + số chưa đọc), `POST /api/admin/alerts/read {ids | all}`. Lấy căn từ `viewer.houseIds` (chủ trọ: mọi căn; quản lý: căn được giao), gom theo chủ trọ đọc từng kho; id của căn khác → 403.
- Tạo cảnh báo: `settleRent` (SePay/BankHub, cả phát lại deferred) → `invoice_paid` khoá `paid:<invoiceId>`, hoặc `overpaid` khoá `sepay:<sepayId>` khi hoá đơn đã trả từ trước; `applyPaymentStatus` (đánh dấu tay paid/cash) → `invoice_paid`; `recompute` khi nó chuyển hoá đơn sang paid. Webhook gửi lại: tiền không ghi lại (reference UNIQUE) và cảnh báo `INSERT OR IGNORE` → không trùng.
